
# CAIE - n8n Automation Assignments

### learn. build. operate

## Project Overview

This repository contains workflow automation projects
developed as part of the CAIE Course Program using
self-hosted n8n on Hostinger VPS.

The projects demonstrate AI-powered automation,
API integration, data processing and automated
communication.

## Automation Projects

| Project | Description | Status |
|---|---|---|
| [Slack Recipe Bot](./Slack_Recipe_Bot_Assignment) | AI-powered recipe generation through Slack | Completed |
| [Google Sheets to Gmail](./Google_Sheets_Gmail_Assignment) | Automated student course status email report | Completed |

## Project 1 - Slack Recipe Bot

An automated Slack recipe assistant that processes
user requests, generates recipe suggestions using AI,
and delivers responses through Slack.

### Key Features

- Slack integration
- AI-powered recipe generation
- Automated message processing
- Automated Slack responses

## Project 2 - Google Sheets to Gmail

An automated workflow that retrieves student data
from Google Sheets, generates a structured HTML
report using JavaScript, and sends it through Gmail.

### Key Features

- Google Sheets integration
- JavaScript data processing
- Dynamic HTML email generation
- Student course status summary
- Automated Gmail delivery
- Zero AI token consumption

## Repository Contents

Each assignment folder contains its workflow JSON,

## How to Run

1. Download the required workflow JSON file.
2. Import the workflow into n8n.
3. Configure the required credentials.
4. Update the necessary workflow parameters.
5. Execute and verify the workflow.
